倒晶格

倒晶格向量滿足 a*·a = 1、a*·b = 0（b* 同理）。每個倒晶格點 Ghk 對應一族實空間晶面 (hk)：方向垂直於晶面，長度為晶面間距的倒數。

Ghk = h a* + k b*, |Ghk| = 1 / dhk

Ewald 球的建立

把入射波向量 k₀ 的尾端放在球心 C，箭頭指向倒晶格原點 O (00)。以 C 為中心、1/λ 為半徑畫球，原點 O 必在球面上。

|k₀| = |k| = 1/λ（彈性散射）

繞射條件

任何落在球面上的倒晶格點 G 都滿足 Laue 條件，繞射光束沿 C → G 方向射出。這與布拉格定律等價，散射角為 2θ。

k − k₀ = G ⇔ 2d sinθ = λ

極限球

晶體轉到任何方位，Ewald 球掃過的範圍是以 O 為中心、半徑 2/λ 的極限球。球外的點永遠無法繞射，也就是 d < λ/2 的晶面不會出現。

|G| ≤ 2/λ ⇔ d ≥ λ/2

旋轉晶體法

旋轉晶體等於讓倒晶格繞 O 轉動。每當一個倒晶格點穿過球面，就出現一道繞射光。按「旋轉晶體」可觀察並記錄這些事件。

電子繞射

200 kV 電子的 λ ≈ 0.025 Å，球半徑約 40 Å⁻¹，相對於倒晶格間距幾乎是平面，因此一次就能截到整個倒晶格平面上的多個點，形成點陣繞射圖樣。
